## 🔍 How to Find Things

### By Category
- **All proposals**: Browse `docs/proposals/`
- **All policies**: Browse `docs/policies/`
- **All good practices**: Browse `docs/good-practices/`
- **Meeting notes**: Browse `docs/meeting-notes/`

### Using GitHub Search
1. Use the search box at the top of the page
2. Filter by labels in Issues
3. Search discussions by category

### By Label (in Issues)
- `proposal` - New course or program proposals
- `policy` - Policy discussions and drafts
- `good-practice` - Teaching practices and tips
- `needs-review` - Items requiring feedback
- `task` - Action items
- `high-priority` - Urgent matters
