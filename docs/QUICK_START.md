# Quick Start Guide

Welcome to the Curriculum Team Collaboration Repository! This guide will get you started in 5 minutes.

## Step 1: Create a GitHub Account (2 minutes)

1. Go to https://github.com
2. Click "Sign up"
3. Follow the steps to create your account
4. Verify your email

## Step 2: Access the Repository (1 minute)

1. Go to https://github.com/djmhunt/Team_coordination_example
2. Click "Watch" → "All Activity" (top right) to get notifications
3. Click "Star" to bookmark it
4. Explore the tabs at the top: Code, Issues, Discussions, Projects, Wiki

## Step 3: Try the Features (2 minutes)

### Browse Issues
1. Click the **Issues** tab
2. Look at existing proposals and discussions
3. Click on one to read the full conversation

### Explore Documents
1. Click the **Code** tab
2. Click on the `docs` folder
3. Browse templates, proposals, and policies
4. Click on any file to read it

### Check the Wiki
1. Click the **Wiki** tab (if enabled)
2. Read the knowledge base articles

## What to Do Next

Choose your path:

### I Want to Submit a Proposal
1. Read the [Course Proposal Template](templates/course-proposal.md)
2. Create an issue using the "Course Proposal" template
3. Fill in the details and submit

### I Want to Share a Teaching Practice
1. Look at [example good practice](good-practices/think-pair-share.md)
2. Create an issue using the "Share a Good Practice" template
3. Describe what worked for you

### I Want to Discuss a Policy
1. Review the [Policy Template](templates/policy-template.md)
2. Create an issue using the "Policy Discussion" template
3. Invite feedback from colleagues

### I Just Want to Learn
1. Read the [Full GitHub Guide](GITHUB_GUIDE.md)
2. Browse existing [proposals](proposals/), [policies](policies/), and [good practices](good-practices/)
3. Join discussions and add comments
