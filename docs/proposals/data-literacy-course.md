# Course Proposal: Introduction to Data Literacy

## Course Information

**Course Title**: Introduction to Data Literacy for Educators

**Course Code**: EDU-201

**Credits/Hours**: 3 credits / 45 contact hours

**Level**: Intermediate

**Prerequisites**: None (designed for non-technical educators)

## Rationale

**Why is this course needed?**
In today's data-driven educational landscape, teachers need to understand how to interpret assessment data, research findings, and educational statistics. This course fills a critical gap by providing educators with practical data literacy skills without requiring advanced mathematics or programming knowledge.

**Target Audience**: 
- Current teachers seeking professional development
- Pre-service teachers in education programs
- Educational administrators
- Curriculum developers

**Learning Outcomes**:
By the end of this course, students will be able to:
1. Critically evaluate data visualizations and statistical claims in educational research
2. Use basic data analysis tools to explore student performance patterns
3. Create clear, effective visualizations to communicate educational insights
4. Identify common misuses of data in educational contexts
5. Make evidence-based decisions using educational data

## Course Content

**Main Topics**:
1. Fundamentals of Data Literacy
   - What is data literacy and why it matters in education
   - Types of educational data
   - Basic statistical concepts for educators

2. Interpreting Educational Research
   - Reading and evaluating research papers
   - Understanding effect sizes and significance
   - Identifying bias and limitations in studies

3. Working with Assessment Data
   - Analyzing student performance data
   - Creating meaningful reports for stakeholders
   - Using data to inform instruction

4. Data Visualization
   - Principles of effective visualization
   - Tools for creating charts and graphs
   - Avoiding misleading visualizations

5. Ethical Considerations
   - Student data privacy
   - Equity in data collection and interpretation
   - Avoiding data-driven decision pitfalls

**Teaching Methods**:
- Interactive workshops with real educational datasets
- Case studies of data use in schools
- Collaborative analysis projects
- Guest speakers from educational research

**Assessment Methods**:
- Weekly reflective journals (30%)
- Group project: Analyze and present school data (30%)
- Case study critiques (20%)
- Final portfolio showcasing data literacy skills (20%)

## Resources Required

**Instructor Expertise**: 
- Background in educational research or assessment
- Experience with data analysis (can partner with statistics department)
- Understanding of K-12 educational contexts

**Materials/Equipment**: 
- Access to computer lab or student laptops
- Free data analysis tools (Google Sheets, Excel, Tableau Public)
- Sample educational datasets (de-identified)
- Subscription to educational research databases
